# Побег из Сколки

2D-платформер в одном HTML-файле. Пятница, 15:59 — нужно сбежать из школы через библиотеку, туалеты, медиастудию, мастерскую, IT-класс и атриум, где ждёт финальный босс.

## Как играть

Играть прямо в браузере: https://vlasyazoy-oss.github.io/skolka-escape-play/

| Клавиши | Действие |
|---|---|
| ← → / A D | бег |
| ↑ / W / Пробел | прыжок (у стены — отскок) |
| J / X | бумажный самолётик |
| ↓ + прыжок | спрыгнуть с платформы |
| E / Q | позвать Илью (1 раз за игру) |
| P / Esc | пауза |
| 4 | секретный режим |

На каждом уровне нужно найти **пропуск**, иначе турникет на выходе не откроется.

Все персонажи вымышлены, совпадения случайны.
